TutorGuide AI – Real-Time AI Coaching Assistant for Peer Math Tutors

TutorGuide AI is an AI-powered instructional coaching assistant designed to support peer math tutors during live tutoring sessions. Unlike traditional AI tutors that teach students directly, TutorGuide AI acts as an invisible teaching coach, helping tutors deliver better explanations, identify misconceptions, generate scaffolded hints, recommend next teaching steps, and create personalized practice problems in real time.

The system continuously analyzes tutoring conversations through live speech transcription and provides instant pedagogical guidance while preserving the tutor as the primary instructor. After each session, it generates a reflection report highlighting student misconceptions, tutoring effectiveness, and areas for improvement.
